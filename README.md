# Earthy Brutal Shopify Theme

A Shopify theme with an earth-toned brutalist visual system. It includes custom sections for homepage, collection, product, cart, and navigation flows.

## Highlights

- Heavy borders, hard shadows, and earthy palette choices
- Custom Liquid sections for core storefront pages
- Structured to work well as a reusable theme starting point

## Quick start

```bash
shopify theme dev
```

Then configure the included sections in the Shopify theme editor to wire up hero content, featured collections, and footer menus.
